What gets shared, and with whom

When an MCP client calls a tool, the message text it retrieves is sent to that client's provider — currently — and is processed under that provider's terms, not this application's.

Data already disclosed to a provider cannot necessarily be recalled. Revoking access here stops future disclosure and deletes the local copy; it does not undo a disclosure that has already happened.
